# Reserved V8 authoring and separation notes

This is a conditional future training proposal. The 240 positive pairs use six deliberately balanced structural families, 40 pairs each, with 28 edits and 12 meaningful unchanged controls. They are individually authored assistant synthetic examples, not 240 independent naturally occurring dictations or a new evaluation set. No source recipe, model, active 2,754-row file or 32-pair UL artifact has been changed. The data may remain unused if the current UL experiment meets its gate.

Authoring used only the supplied residual taxonomy. No retired, development or fresh evaluation case text/output was opened or copied for this task. Post-authoring duplicate comparison loaded only fingerprints from the author's prior approved 270 and 100 training components, without surfacing their text. It found zero exact inputs, targets or pairs under NFC, casefold and whitespace collapse. This is not actual production Core normalization and is not a fresh-set overlap check. Root still owns those later checks.

The current author preflight has 240 unique IDs and input strings, 168 edits, 72 controls, ten quoted payloads preserved once in source order, and 28 source cases of 40–51 words. Other sources are 9–39 words. Longer cases were manually composed with interacting facts and constraints rather than copied from evaluation examples. Structural patterns are intentionally repeated so the small model can learn conditional scope distinctions; those repetitions do not increase the independent content count.

All raw source/target pairs received author semantic review. Independent actual-pair review is assigned to root for families 1/4, training_audit for 2/5, and cleanup_pipeline_review for 3/6. Their create-only casewise reviews bind exact source hashes. Corrections create new part versions and explicit overlays; previous drafts/reviews remain historical and are never silently overwritten. Only the final named combined file may later be considered for training. Old versions and overlays are not additional examples.

No model inference, native job, build, Torch import or source implementation is needed for this authoring work. A future no-model Core fixture and literal-mask validation may be prepared after all independent reviews complete, but preparation is not activation. No unused V8 data should be described or curated as actually trained.
